# Лабораторная работа

## 1. Название и цель:
Лабораторная работа по информатике.
Цель: создание собственного репозитория в GitHub, освоение его функций и возможностей. 

## 2. Состав файлов:
- notebooks/ - папка с файлами Google Colab
- data/ - папка с исходными данными
- docs - документация и отчёты
- metadata.tsv - метаданные проекта
- version_log.md - история изменений проекта
- README.md - описание проекта

## 3. Как открыть:
1. Открыть папку проекта my-project
2. Перейти в папку notebooks/
3. Открыть файл в Google Colab
4. Запустить все ячейки по порядку
5. Проверить данные в папке data/ и отчёт в папке docs/ при необходиости

## 4. Проверка:
Если все ячейки notebook работают без ошибок и результаты выводятся в соответствии с заданием, то проект работает корректно.

## 5. Ограничения:
Результаты зависят от исходных данных и используемой среды выполнения. 
Работа внешних ресурсов, если они используются в Notebook, может зависеть от их доступности.
